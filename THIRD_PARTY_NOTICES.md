# Third-party notices

Brasscribe's own code is licensed under MIT OR Apache-2.0 ([LICENSE](LICENSE)). It uses the software,
fonts, sounds and models below, which keep their own licences. This file lists what the apps ship
(bundled), what they download on the user's computer (not bundled), and what only the development
tools use.

Each app ships the licence texts of what it bundles, in one file that About opens. The files are written from
[licences/components.json](licences/components.json) ([licences/README.md](licences/README.md)), and a check fails
when a dependency of a build is missing there.

## Other dependencies

- **Engine (Python):** installed by `pixi install` from conda-forge and PyPI (versions pinned in
  `pixi.lock`); Bandroom runs the same install on the user's computer on first launch. Notable:
  music21 (BSD-3-Clause), FastAPI (MIT), PyTorch (BSD-3-Clause).
- **Bandroom** (Mac and Windows) ships the [pixi](https://github.com/prefix-dev/pixi) binary (BSD-3-Clause),
  and the project's own `scribe-core` command-line tool, built from the Rust core below.
- **Rust core:** crates under MIT, Apache-2.0, BSD-style or Unicode-3.0 licences, plus UniFFI (MPL-2.0,
  above). `cargo metadata` in `core/` lists them.
- **Android** (Play and Fretscribe): AndroidX and Jetpack Compose (Apache-2.0), Kotlin coroutines and
  serialization (Apache-2.0), Ktor (Apache-2.0) with OkHttp (Apache-2.0), Oboe (Apache-2.0), JNA
  (Apache-2.0 option of LGPL-2.1/Apache-2.0), CameraX (Apache-2.0) and
  [ZXing](https://github.com/zxing/zxing) core (Apache-2.0), which read the pairing QR code on the phone.
  Play for Android also has ONNX Runtime (MIT), for the models it listens with.
- **Fretscribe for Android** is built from the same code as Play for Android. Its release APK ships
  alphaTab with Bravura and the Sonivox SoundFont, alphaSkia and AndroidX Media3 (the table above), the
  Rust core with UniFFI, the Android libraries in the line above, and its two fonts, Atkinson
  Hyperlegible Next and Fretscribe Tab, with their licence texts. It does not ship sfizz or what comes
  linked in with it, a band SoundFont, a model or ONNX Runtime to run one, or Instrument Serif.
- **Fretscribe for Mac, iPhone and iPad** ships alphaTab's browser build with Bravura and its licence texts (fetched
  from the npm release by `apps/apple/scripts/fetch-alphatab.sh`, not its SoundFont), drawn in the system's web view,
  and its two fonts, Atkinson Hyperlegible Next and Fretscribe Tab, with their licence texts. It plays the recording
  with the system's AVFoundation. It does not ship Verovio, the Rust core, a band SoundFont or a model.
- **Windows:** Windows App SDK (Microsoft software licence), the .NET runtime (MIT), ONNX Runtime with DirectML (MIT),
  NAudio (MIT), CommunityToolkit.Mvvm (MIT). The Windows App SDK's and the .NET runtime's own notice files ship beside
  the app's licence file, as they come in their packages. Play for Windows also ships `vcruntime140.dll`, a
  redistributable file of the Microsoft Visual C++ runtime (Visual Studio licence terms), which ONNX Runtime
  needs.
- **ONNX Runtime sends data to Microsoft.** It is Microsoft's, and Brasscribe uses Microsoft's builds as
  they are, with their telemetry on: in Play for Android, in Play for Windows, and in the engine's swift-f0
  and separator adapters and, outside macOS, its basic-pitch adapter (the `onnxruntime` package from PyPI,
  on the computer Bandroom or a checkout runs on). Its `Privacy.md` says it collects "information about you
  and your use of the software" and sends it to Microsoft. On Android, macOS and Linux its own uploader
  sends events about the runtime's use to Microsoft's telemetry service
  (`mobile.events.data.microsoft.com`) with a device identifier that it keeps between runs; on Android
  it also reads the device's id (`ANDROID_ID`), maker and model. On Windows the events go through ETW to
  Windows' diagnostic data, as far as the PC's settings allow. A recording, or the notes written from it,
  is not part of what it sends. Microsoft's privacy statement: https://go.microsoft.com/fwlink/?LinkID=824704.
- **Studio:** alphaTab (above); build and test tools only in development.

## Not distributed

The evaluation datasets (ChoraleBricks CC BY 4.0, GuitarSet CC BY 4.0, URMP, Slakh) and the PANNs tagger used for
research are downloaded on request by the development tools and never bundled. The repository keeps
small derived test data, and two short excerpts for the public site:

- `eval/fixtures/`: MIDI, beats and pitch contours computed from the ChoraleBricks v1.1.0 recordings
  (CC BY 4.0, Zenodo 10.5281/zenodo.20849469; see `eval/README.md`). Bandroom's bundled workspace
  includes this folder.
- `site/brasscribe/take/` and `site/brasscribe/figures/`: 14.6 s of the opening of J. S. Bach's "Ich steh an deiner
  Krippe hier" from ChoraleBricks v1.1.0 (S. Balke, A. Berndt, M. Müller; CC BY 4.0, Zenodo 10.5281/zenodo.20849469),
  two trumpets, a baritone and a tuba mixed to mono (`take.mp3`), with what the engine wrote from it. Shown and
  played on the public site, with this credit. Made by `site/brasscribe/make_take.py`.
- `site/fretscribe/take/` and `site/fretscribe/figures/`: 15.2 s of take `04_SS3-98-C_comp` of GuitarSet (Q. Xi,
  R. Bittner, J. Pauwels, X. Ye, J. P. Bello, ISMIR 2018; CC BY 4.0, Zenodo 10.5281/zenodo.3371780) as mono
  `take.mp3`, with what the engine wrote from it. Shown and played on the public site, with this credit. Made by
  `site/fretscribe/make_take.py`.
- `apps/android/features/score/pitch/src/test/resources/`: Basic Pitch notes and Beat This! beats of 30 s of one URMP
  track (URMP, University of Rochester; B. Li et al., IEEE Trans. Multimedia 2019).
