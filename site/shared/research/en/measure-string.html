• String agreement and string recall

    On a fretted instrument a pitch can usually be played at several positions. Let M be the matched notes of {{ref eq:prf}}, S ⊆ M those written on the string the player used (and hence at the same fret), and Nref the number of reference notes:

    string agreement = |S| / |M|,   string recall = |S| / Nref {{label eq:string}}

    These are note-level counterparts of the frame-level tablature disambiguation rate and tablature recall of Wiggins and Kim {{cite wiggins2019tabcnn}}; values at the two levels are not directly comparable.
